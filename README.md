# Retail Demand Forecasting & Inventory Planning

A 7-day-ahead demand forecasting system for multi-store retail, with inventory recommendations
(safety stock and reorder points) and an interactive Streamlit dashboard.

> **Data note:** the dataset is **synthetic** (generated by `src/generate_data.py`) so the project is fully
> reproducible. It mimics retail patterns: trend, weekly/yearly seasonality, festive-season spikes and promotions.

## Business problem
Retailers lose sales to stock-outs and tie up cash in excess inventory. Accurate short-term demand
forecasts per store and category allow better replenishment decisions.

## Approach
1. **Data generation** - 8 stores x 5 categories x 2 years = 29,240 daily records.
2. **Feature engineering** - lag features (7/14/28 days), rolling mean/std, calendar features, promo & festive flags.
   All lags are at least 7 days old, so there is **no target leakage** for a 7-day horizon.
3. **Modelling** - `HistGradientBoostingRegressor` with categorical store/category handling.
4. **Validation** - time-based hold-out (Oct-Dec 2024, includes the festive season), never a random split.
5. **Baselines** - seasonal naive (same weekday last week) and 28-day moving average.
6. **Inventory planning** - safety stock = z x forecast-error std x sqrt(lead time); reorder point = lead-time demand + safety stock (95% service level, 7-day lead time).
7. **Dashboard** - Streamlit app with store/category filters.

## Results (held-out test period)
| Model | WAPE | MAE | RMSE |
|---|---|---|---|
| **Gradient boosting** | **9.6%** | 9.69 | 12.66 |
| Seasonal naive (lag-7) | 19.2% | 19.39 | 27.88 |
| Moving average (28d) | 26.4% | 26.65 | 35.24 |

The model reduces WAPE by **~50%** versus the best baseline. See `outputs/forecast_vs_actual.png`.

## Run it
```bash
pip install -r requirements.txt
python src/train.py              # generates data, trains, writes outputs/
streamlit run src/app.py         # launches the dashboard
```

## Project structure
```
src/generate_data.py   synthetic data generator
src/features.py        leakage-safe feature engineering
src/metrics.py         WAPE / MAE / RMSE
src/train.py           training, evaluation, inventory recommendations
src/app.py             Streamlit dashboard
outputs/               metrics.json, predictions.csv, inventory_recommendations.csv, chart
```

## Possible extensions
Hierarchical forecasting, prediction intervals (quantile regression), external features (weather, holidays), MLflow tracking, deployment on Azure/Databricks.

**Tech:** Python, pandas, NumPy, scikit-learn, SciPy, Matplotlib, Streamlit
